# Contributing to Mechy

Bug reports, reproducible examples, documentation improvements and code
contributions are welcome. Identify the source and licence of any third-party
material; preserve its required notices.

## Contribution rights

The public core is AGPL-3.0-only, with a separate commercial licensing route.
Contributors retain their copyright unless a separate agreement explicitly
provides otherwise. A pull request or ordinary AGPL grant alone does not give
the maintainer permission to relicense someone else's contribution commercially.

Before merging a copyrightable contribution into the commercially licensable
core, the maintainer must obtain a separate written contribution agreement or
other explicit permission sufficient for both AGPL publication and commercial
sublicensing, including any necessary patent permissions. It must cover the
identified contribution and any employer or third-party rights involved.
This document is a contribution policy, not a substitute for that agreement;
submission does not imply signature or consent to undisclosed terms.

Do not incorporate third-party GPL/AGPL-only code into a commercial release
without a compatible grant from its rights holders. Report proposals for such
dependencies before adding them so their distribution scope can be assessed.

## Review

Keep changes focused, document model assumptions and provenance, and include
tests for changed calculation behavior. General-purpose improvements should
be proposed upstream where permission allows. Never include confidential
customer models, datasets or parameters without authorization.
